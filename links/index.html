4 free GitHub repos that make Claude Code way better

Three are Claude Code plugins, one is a skill with its own command-line tool. All four are free and open source.

  • Superpowers

    plugin★ 290K

    Before writing code it asks what you're actually building, writes a plan you can read, then works through it with tests at every step.

    /plugin install superpowers@claude-plugins-official

  • Context7

    plugin · MCP★ 62K

    Hands Claude current, version-specific docs for the library you're using, so it reaches for functions that still exist.

    /plugin install context7@claude-plugins-official

  • Graphify

    skill + CLI★ 120K

    Turns your codebase into a knowledge graph Claude can look things up in, instead of rereading the same files. Building the graph uses no LLM credits.

    uv tool install graphifyy
graphify claude install

  • Ponytail

    plugin★ 144K

    Makes Claude work like a lazy senior developer: reuse what exists, use the platform, write the minimum. It never cuts security, validation or error handling.

    Author's benchmark: 12 real Claude Code tasks, Haiku 4.5, 4 runs each. 54% less code, 22% fewer tokens, 20% lower cost. A date picker went from 404 lines to 23. Read the writeup.

    /plugin marketplace add DietrichGebert/ponytail
/plugin install ponytail@ponytail

Send the two Ponytail commands as separate prompts. Star counts as of Sep 22, 2026.

Jev vs ChatGPT: this AI doesn't write back

A chatbot writes a paragraph your code then has to turn back into yes or no. Jev reads the same input and returns just the answer, with how sure it is.

  • Jev by TypeSafe

    AI modelearly access

    You send a situation and questions with every allowed answer declared up front. It returns those answers with probabilities. Priced on input: $0.042 per million tokens, output not charged.

    It can't answer outside your options, but it can still pick the wrong one. Test it on your own data first.

  • TypeSafe docs

    docs

    The three question types (Choice, Score, Noul), confidence, and worked cookbooks for routing, reranking and extraction.
