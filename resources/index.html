Chat assistants

The big general-purpose AIs you talk to. Most are free to start.

  • Claude

    Anthropic

    we use this

    Strong at writing, reasoning and long documents. The one Capp would pick.

    Good for: writing, analysis, long files

  • ChatGPT

    OpenAI

    The most widely used chat assistant, with image generation and voice built in.

    Good for: everyday questions, images, voice chat

  • Gemini

    Google

    Google's assistant, tied into Search, Gmail, Docs and YouTube.

    Good for: Google Workspace, research

  • Grok

    xAI

    xAI's assistant, with live access to posts on X.

    Good for: what people are saying right now

  • DeepSeek

    DeepSeek

    Open-weight models that are cheap to run, popular with developers.

    Good for: low-cost coding and reasoning

  • Perplexity

    Perplexity

    An AI search engine that answers with sources you can click.

    Good for: research with citations

Coding with AI

Tools that write, edit and run code with you.

  • Claude Code

    Anthropic

    we use this

    An AI coding agent that works in your terminal, desktop app or IDE and edits real projects. Every Drip video is built with it.

    Good for: building whole apps and tools

  • Cursor

    Anysphere

    A code editor with AI built into every step.

    Good for: coding inside an editor

  • Codex

    OpenAI

    OpenAI's coding agent, in the terminal, IDE and cloud.

    Good for: delegating coding tasks

  • GitHub Copilot

    GitHub

    AI suggestions and an agent inside the editors and GitHub itself.

    Good for: autocomplete, pull requests

Claude Code skills and plugins

Free add-ons that change how Claude Code works. A plugin installs with /plugin install; a skill is a folder of instructions Claude reads when it's relevant.

  • Superpowers

    ★ 290K

    obra

    plugin

    Asks what you're building, writes a plan, then works through it with tests at every step.

    Good for: bigger builds that need a plan

    /plugin install superpowers@claude-plugins-official
    seen in: 4 free repos for Claude Code

  • Context7

    ★ 62K

    Upstash

    plugin · MCP

    Gives Claude current, version-specific docs so it uses functions that still exist.

    Good for: fast-moving libraries

    /plugin install context7@claude-plugins-official
    seen in: 4 free repos for Claude Code

  • Graphify

    ★ 120K

    Graphify Labs

    skill + CLI

    Turns a codebase into a knowledge graph Claude looks things up in, instead of rereading files.

    Good for: large codebases, fewer tokens

    uv tool install graphifyy
graphify claude install
    seen in: 4 free repos for Claude Code

  • Ponytail

    ★ 144K

    Dietrich Gebert

    plugin

    Makes Claude work like a lazy senior dev: reuse, use the platform, write the minimum. On the author's benchmark, 54% less code and 22% fewer tokens.

    Good for: cutting code and token use

    /plugin marketplace add DietrichGebert/ponytail
/plugin install ponytail@ponytail
    seen in: 4 free repos for Claude Code

  • Frontend Design

    Anthropic

    plugin

    Anthropic's official plugin for distinctive, non-generic web design.

    Good for: sites that don't look AI-made

    /plugin install frontend-design@claude-plugins-official

AI models for your own apps

For when you want AI inside something you're building, not a chat window.

  • Claude API

    Anthropic

    Claude's models for your own software, plus tools for agents.

    Good for: writing, agents, long context

  • OpenAI API

    OpenAI

    GPT models, image and voice models through one API.

    Good for: general-purpose apps

  • Jev

    TypeSafe

    early access

    Doesn't write back. You declare the allowed answers; it returns them with probabilities. Priced on what it reads.

    Good for: sorting, routing, yes/no decisions at scale

    seen in: Jev vs ChatGPT

  • OpenRouter

    OpenRouter

    One API key for hundreds of models from different labs.

    Good for: trying many models, fallbacks

Voice and audio

Voiceover, music and turning speech into text.

  • ElevenLabs

    ElevenLabs

    we use this

    Realistic AI voices, voice design, dubbing and sound effects. Drip's and Capp's voices are made here.

    Good for: voiceover, character voices

  • whisper.cpp

    open source

    we use this

    OpenAI's Whisper speech-to-text, running locally and fast on your own computer. Free.

    Good for: transcripts, word-level timing

  • Suno

    Suno

    Makes full songs, vocals included, from a text prompt.

    Good for: music beds, jingles

  • Midjourney

    Good for: art direction, mood boards

    Detailed image models that follow prompts closely.

  • Ideogram

    Ideogram

    Image generation with reliable typography.

Editing

  • Descript

  • DaVinci Resolve

    Blackmagic Design
